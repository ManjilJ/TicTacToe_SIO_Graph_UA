🔐 Authentication & Security Flow

Complete authentication flow from registration through token validation on every request.

Registration & Login Process

Step Action Component Details
1 User enters credentials Auth.js Form Username & password input
2 Submit form handleSubmit() POST /register or /login
3 Server receives request Express Endpoint Validate username & password
4A New user registration bcryptjs Hash password with 10 salt rounds
4B Existing user login bcryptjs Compare input with stored hash
5 Save or verify SQLite3 INSERT new user or verify match
6 Generate JWT token jsonwebtoken 7-day expiry, sign with JWT_SECRET
7 Send token to client HTTP Response JSON: { token, username }
8 Store token locally App.js localStorage.setItem("token")
9 Add to requests Axios headers Authorization: Bearer TOKEN
10 Socket connection Socket.IO auth Verify JWT in io.use middleware
11 Connected & authenticated TicTacToe.js Ready to play game

Security Mechanisms

Security Layer Technology Purpose Implementation
Password Hashing bcryptjs Secure password storage 10 salt rounds, one-way hash
Token Generation jsonwebtoken Stateless authentication JWT signed with JWT_SECRET
Token Expiry JWT config Time-limited access 7 days validity period
CORS Express CORS Prevent cross-origin attacks Whitelist allowed origins
Socket Auth Socket.IO middleware Secure WebSocket connections Verify JWT before connection

🎯 Game Logic & Move Processing

Step-by-step flow of how a move is validated, processed, and synchronized across all players.

Move Processing Steps

Step Action Location Details
1 User clicks board cell TicTacToe.js UI Click handler on cell button
2 Emit move event Socket.IO Client socket.emit('move', {index})
3 Server receives move server.js handler socket.on('move') triggered
4 Validate move Game Service Check: cell empty, player's turn, game not won
5 Update board gameObject board[index] = 'X' or 'O'
6 Toggle turn gameObject isXNext = !isXNext
7 Check winner checkWinner() Check 8 winning patterns (rows/cols/diags)
8A If winner found Database UPDATE users SET wins = wins + 1
8B If draw detected gameObject winner = 'Draw'
9 Broadcast update Socket.IO Server io.emit('update', gameObject) to all clients
10 Clients update state TicTacToe.js React state: setBoard, setWinner, setWhoseTurn
11 Render animations React component Cell zoom, winning line draw
12 Move complete All clients Board updated, visible to all players
